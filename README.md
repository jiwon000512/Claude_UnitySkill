# Claude_UnitySkill

Claude Code 사용자 전역 스킬 모음. `~/.claude/skills`에 clone해서 쓴다.

```bash
git clone https://github.com/jiwon000512/Claude_UnitySkill.git ~/.claude/skills
```

| 스킬 | 용도 |
|---|---|
| `unity-project-setup` | 유니티 모바일 게임 프로젝트 초기 세팅(git, 폴더 구조, 패키지 정리, 세로 고정, CLAUDE.md, JSON 데이터 테이블 규칙, GitHub 연결). `/unity-project-setup` |

규칙: 각 스킬 폴더가 그 지식의 원본이다. 게임 저장소에는 가이드를 복제하지 않고 CLAUDE.md에 그 프로젝트가 고른 값만 남긴다.
